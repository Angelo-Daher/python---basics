# python---basics

Este repositório reúne pequenos projetos desenvolvidos em Python com o objetivo de consolidar os fundamentos da linguagem e praticar lógica de programação.

## Tecnologias

- Python 3
- Git
- GitHub

## Conceitos praticados

- Variáveis
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Listas
- Tuplas
- Dicionários
- Manipulação de Strings

## Objetivo

Meu foco é construir uma base sólida em programação antes de avançar para projetos maiores e aplicações web.
